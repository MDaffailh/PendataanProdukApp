Aplikasi ini dibuat untuk memenuhi tugas individu Pemrograman Lanjut, fungsinya 
adalah untuk membantu user mendata barang produknya.

Atribut yang digunakan ada NamaProduk, Kode Produk, Harga Produk, dan Kategori.

![Form Awal APP](./contoh-gambar/Screenshot%2026-11-09%023330.png)

Lalu silahkan masukkan KodeProduk, NamaProduk, Kategori Produknya (bagian ini 
dapat diubah menggunakan tombol arrow, kalau pakai mouse ntah kenapa eror), Lalu
Terakhir masukkan harga produknya. Jika sudah, terakhir anda dapat menambahkan 
gambar untuk produknya.

Selanjutnya anda akan masuk ke bagian detail produk, kita bisa melihat detail
produknya. Terakhir anda dapat melihat daftar produk, yang berisikan semua 
daftar produknya.
